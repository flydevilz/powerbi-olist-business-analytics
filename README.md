# Olist Business Intelligence Dashboard

An end-to-end Business Intelligence project developed using the Brazilian Olist E-Commerce dataset. The project demonstrates ETL, dimensional modeling, DAX, and dashboard development in Power BI to support executive decision-making.

---

## Project Overview

This project aims to transform raw e-commerce data into actionable business insights through interactive dashboards.

Key business questions include:

- How is revenue changing over time?
- Which sellers contribute the most revenue?
- Which customers have the highest lifetime value?
- How efficient is order delivery?
- Which product categories perform best?
